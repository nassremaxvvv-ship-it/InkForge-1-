# InkForge Engine 0.1.0

محرك رسم مستقل أولي لـ InkForge. هذا مشروع جديد ببنية وكود مستقلين، وليس نسخة من Drawpile ولا يحتوي على ملفات Drawpile.

## الموجود في هذه النسخة
- مكتبة C++17 مستقلة عن واجهة المستخدم والشبكة.
- تخزين نقطي مقسّم إلى بلاطات شفافة بحجم 256×256، مع تخصيص البلاطات عند الحاجة فقط.
- طبقات مع الاسم والظهور والشفافية.
- فرشاة دائرية أولية تدعم الحجم واللون والشفافية والضغط والاستيفاء بين النقاط.
- تراجع وإعادة على مستوى ضربة الفرشاة.
- اختبار دخاني بسيط للرسم والتراجع والإعادة.

## البناء والاختبار
يتطلب CMake 3.16 أو أحدث ومترجم C++ يدعم C++17.

```sh
cmake -S . -B build -DINKFORGE_BUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

## ما لم يُنفّذ بعد
هذا أساس قابل للبناء والتوسعة، وليس محركًا بمستوى Drawpile بعد. لا توجد حتى الآن صيغة ملفات مشروع، أو تصدير PNG، أو مزج طبقات وعرض مركّب، أو أقنعة وتحديد وتحويل، أو فرش نسيجية/مخصصة، أو تحسينات أداء متقدمة، أو ربط Android/واجهة InkForge.

## ترتيب التطوير المقترح
1. تركيب الطبقات وعرضها (compositor) مع أوضاع المزج.
2. نظام أوامر وتاريخ قابل للتجزئة وذاكرة محدودة.
3. محرك فرش قابل للإضافات: أشكال الرؤوس، التباعد، التشتت، الملمس، الميل والدوران.
4. التحديد والتحويل والممحاة والتعبئة.
5. الحفظ والاستيراد والتصدير.
6. واجهة ربط Android/JNI ثم اختبارات الأداء على الهاتف.

## الترخيص
هذه الشيفرة الأولية مكتوبة خصيصًا لـ InkForge. قبل دمجها في المستودع الرئيسي، أضف ملف الترخيص الذي يختاره مالك المشروع، واحتفظ بإشعارات GPL-3.0-or-later الخاصة بأي مكونات Drawpile تُستخدم لاحقًا. لا توجد شيفرة Drawpile مضمّنة في هذه الحزمة.
